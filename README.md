# tripeaks — 终端三峰纸牌

TriPeaks solitaire 接龙, 纯 Python 标准库, 终端可玩。

## 玩法

- 牌桌 28 张: 3 个峰(每峰 6 张, 上 1 / 中 2 / 底 3)+ 底行 10 张; 牌库 23 张; 废牌堆首张明牌。
- 把与废牌堆顶**点数相邻**(差 1, 如 5 接 6 或 4)的明牌移到废牌堆。
- 被压住的牌是暗牌(`##`), 压它的牌全部拿走后才翻开。
- 没有可走的牌时从牌库摸一张(连击清零); 牌库摸完且无牌可走则失败。
- 清光 28 张牌桌即胜利。

## 用法

```bash
python -m tripeaks            # 交互游玩(走牌输编号 / d 摸牌 / q 退出)
python -m tripeaks --seed 42  # 固定牌局
python -m tripeaks --auto     # 贪心机器人自动游玩
```

## 计分

连续走牌(中间不摸牌)形成连击: 第 n 次连走得 `10*n` 分(10、20、30…);
摸牌后连击归零。贪心机器人优先走能翻开最多暗牌的牌。

## 设计取舍

- **A 与 2 不相邻**: 点数差必须恰为 1, K-A 可以接, A-2 不可以(无回绕)。
  这是有意选择, 与多数 TriPeaks 实现一致。
- 底行 10 张的压牌关系: 18 只压峰底 3、27 只压峰底 17,
  其余每张压相邻两张峰底牌(如 19 压 3 和 4)。标准三峰的合理变体,
  保证每张峰底牌恰被两张底行牌压住。
- 发牌用 `secrets` 播种(未指定 `--seed` 时), 保证不可预测。

## 已知局限

- 行输入模式, 每步需回车; 不支持鼠标/方向键(需终端 raw 模式)。
- `--auto` 是简单贪心(翻开暗牌最多优先), 不是最优策略, 输多赢少属正常。
- 无悔棋、无存档、无排行榜; 退出即清零。
- 牌面渲染约 77 列宽, 窄终端可能换行错位。
